# Aegis Flow

> A high-performance sprint command center and project workspace.

Aegis Flow is a modern, liquid command center designed for agile teams, fast sprint delivery, and hackathon demo readiness. Built with pure web technologies and zero runtime build overhead.

---

## ⚡ Highlights

- **Sprint Kanban Board**: Effortless task planning with dynamic progress tracking across Backlog, In Progress, Review, and Done.
- **Demo Readiness Radar**: Built-in verification checklist and metrics to ensure software is presentation-ready.
- **Milestone Timeline**: Visual roadmap signals keeping sprints aligned with key delivery dates.
- **Command Palette (`Ctrl + K`)**: Keyboard-first rapid navigation and global search (`/`).
- **Ambient Canvas Visualizer**: Real-time project pulse visualization and ambient lighting.
- **Scratchpad & Reminder Center**: Instant note-taking and active deadline notifications.

---

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/kkartikey361-create/aegis-flow.git
cd aegis-flow
```

No package manager or build step required.
