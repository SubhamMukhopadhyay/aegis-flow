# Aegis Flow

> A high-performance sprint command center, activity audit hub, and project workspace.

Aegis Flow is a modern, liquid command center designed for agile teams, fast sprint delivery, and hackathon demo readiness. Built with pure web technologies and zero runtime build overhead.

🌐 **Live Demo:** [https://aegis-flow-one.vercel.app/](https://aegis-flow-one.vercel.app/)

## ⚡ Highlights & Features

- **Sprint Kanban Board**: Dynamic task planning across Backlog, In Progress, Review, and Done with live completion metrics and fluid interaction.
- **Activity Feed & Audit Trail**: Comprehensive logging of team interactions with category filter chips (`All`, `Created`, `Edited`, `Moved`, `Completed`, `Deleted`) and persistent preferences.
- **JSON Activity Export**: One-click export of the entire activity audit trail into a clean, formatted JSON file.
- **Hackathon Deadline Countdown**: Live real-time deadline tracker synced to October 10, 2026, 11:59 PM IST.
- **Demo Readiness Radar**: Built-in verification checklist and readiness score to ensure presentation readiness before pitch time.
- **First-Visit Onboarding & Demo Reset**: Preloaded sample sprint tasks and notes for immediate exploration, with persistent storage and a single-click demo reset.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Keyboard-first rapid navigation, task actions, and global search (`/`).
- **Scratchpad & Notes**: Built-in quick notes buffer with persistent local storage.
- **Ambient Canvas Visualizer**: Real-time project pulse visualizer and ambient canvas backdrop.

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/SubhamMukhopadhyay/aegis-flow.git
cd aegis-flow
```

No external dependencies, package managers, or build steps required.
